    Person Organization Location Event Object Observation

    3 capas de memoria

    Short-termMensajes por sesion/canal. Nodos: Session, Message
    Long-termKnowledge graph POLE+O. Entidades, relaciones, observaciones
    ReasoningTrazas de decisiones. Nodos: ToolCall, ReasoningStep, SkillInvocation

    Ejemplos de uso con el agente

    Buscar en memoria del grafo
    openclaw agent --message "¿Que sabes sobre el proyecto vocari?"
    → El agente usa memory_search y entity_lookup automaticamente
    Guardar un hecho importante
    openclaw agent --message "Recuerda: vocari.cl usa Supabase como backend y Netlify para deploy"
    → El agente usa memory_store para crear nodos y relaciones
    Consultar relaciones
    openclaw agent --message "¿Quienes estan involucrados en humanloop y que herramientas usan?"
    → El agente usa graph_query con Cypher para traversar relaciones
    Auditar decisiones del agente
    openclaw agent --message "¿Por que decidiste usar n8n en vez de Temporal para humanloop?"
    → El agente usa reasoning_trace para buscar la traza de esa decision

    Configuracion activa

    autoRecallInyecta contexto relevante del grafo antes de cada respuesta del agente
    autoCaptureAlmacena mensajes del usuario despues de runs exitosos
    graphToolsExpone entity_lookup y graph_query al agente
    observationalRegistra trazas de tool calls para auditoria
    readOnlyCypherLas queries desde el dashboard son solo lectura

    Agent-to-Agent (A2A)
    Permite que agentes se envíen mensajes entre sí
    Profundidad de spawn
    Max sub-agentes anidados (1=normal, 2=orquestador)
    Patrones multi-agente disponibles
    🤖→🤖
    Agentes aislados
    Múltiples agentes con distintos canales/identidades. Sin comunicación entre ellos. Ideal para separar trabajo/personal.
    🤖↓🤖
    Sub-agentes
    Agente principal lanza sub-tareas en background. Resultado notificado al completar. Requiere maxSpawnDepth ≥ 1.
    🤖⇄🤖
    Agent-to-Agent
    Agentes se consultan entre sí via sessions_send. Requiere habilitar A2A. Límite de turnos: maxPingPongTurns.
    🤖↗🖥️
    ACP (OpenCode/Codex)
    Lanza harnesses externos (opencode, pi, claude code) con thread binding. Ideal para tareas de programación profunda.
